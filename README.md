# Du Học Hằng Lương - Website Tái Cấu Trúc Toàn Diện 2026

Website chính thức của **Du Học Quốc Tế Hằng Lương**, được thiết kế theo chuẩn nhận diện thương hiệu cao cấp kết hợp những tính năng tinh hoa từ **IDP Education** và **INEC Du Học**.

## 🌟 Tính Năng Nổi Bật

1. **Course Finder Thông Minh**: Bộ lọc tìm kiếm khóa học & trường theo Quốc gia, Ngành học, Bậc học ngay tại Hero Banner.
2. **Cụm 3 Khối Niềm Tin (Social Proof)**:
   - Học sinh nói gì về Hằng Lương (Video cảm nhận thực tế)
   - Câu chuyện thành công (Hồ sơ visa & Học bổng 100%)
   - Bằng khen & Kỷ niệm chương hơn 20 năm (ICEF, Curtin, Navitas, Taylor's, APU)
3. **Đồng Hồ Đếm Ngược Sự Kiện (Live Countdown)**: Lịch triển lãm du học & phỏng vấn học bổng 1:1 tại TP.HCM, Tây Ninh, Đà Lạt.
4. **Hệ Thống 3 Chi Nhánh Chuẩn Hóa**: Trụ sở TP.HCM, Chi nhánh Đà Lạt, Chi nhánh Tây Ninh.
5. **Form Tư Vấn Tối Ưu Chuyển Đổi**: Tự động lưu lead và phản hồi nhanh chóng.
6. **Tối Ưu 100% Cho Vercel**: Cấu hình `vercel.json` với Clean URLs, tối ưu cache assets và bảo mật header.

## 🚀 Hướng Dẫn Deploy Lên Vercel

### Cách 1: Deploy Bằng 1-Click Từ GitHub (Khuyên dùng)
1. Đăng nhập [Vercel](https://vercel.com).
2. Bấm **Add New...** -> **Project**.
3. Tại mục **Import Git Repository**, chọn repository `hangluong-edu-website`.
4. Bấm **Deploy**. Website sẽ chạy trên domain `.vercel.app` trong 15 giây!

### Cách 2: Deploy Bằng Kéo Thả (Drag & Drop)
Kéo thư mục dự án này thả trực tiếp vào ô *"drag and drop your project"* trên Vercel.
